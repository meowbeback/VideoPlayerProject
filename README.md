# 🎬 Видеоплеер

Простой видеоплеер с поддержкой загрузки и воспроизведения видео прямо в браузере.

## 📋 Особенности

- ✅ **Две страницы:**
  - 📤 Страница загрузки видео (с поддержкой drag-and-drop)
  - ▶️ Страница воспроизведения видео
- ✅ **Локальное хранилище** (данные сохраняются в браузере)
- ✅ **Поддерживаемые форматы:** MP4, WebM, Ogg, MOV
- ✅ **Адаптивный дизайн** (мобильные и настольные устройства)
- ✅ **Без зависимостей** (чистый HTML/CSS/JavaScript)

## 🚀 Запуск на localhost

### Способ 1: Python 3 (рекомендуется)
```bash
cd C:\Users\user\TestInterface
python -m http.server 8000
```

Затем откройте в браузере: **http://localhost:8000**

### Способ 2: Python 2
```bash
cd C:\Users\user\TestInterface
python -m SimpleHTTPServer 8000
```

### Способ 3: Node.js (если установлен)
```bash
npx http-server -p 8000
```

### Способ 4: Live Server (VS Code расширение)
1. Установите расширение "Live Server"
2. Кликните правой кнопкой на index.html → "Open with Live Server"

## 📝 Как использовать

### Загрузка видео
1. Перейдите на вкладку "📤 Загрузка видео"
2. Перетащите видеофайл на область загрузки ИЛИ нажмите "Выбрать видео"
3. Видео будет автоматически сохранено

### Воспроизведение видео
1. Нажмите кнопку "Воспроизвести" рядом с нужным видео
2. Видео откроется на вкладке "▶️ Воспроизведение"
3. Используйте встроенные элементы управления (пауза, громкость, полноэкран)

### Удаление видео
1. Нажмите кнопку "Удалить" рядом с видео
2. Подтвердите удаление

## 💾 Хранение данных

- Видео хранятся в **localStorage** браузера
- Данные сохраняются локально и доступны при повторном открытии страницы
- **Ограничение:** ~5-10MB в зависимости от браузера
- При очистке кэша браузера видео будут удалены

## 🐛 Решение проблем

### Видео не загружается
- Проверьте размер видео (не должно превышать лимит localStorage)
- Проверьте формат видео (MP4, WebM, Ogg, MOV)

### Ошибка при запуске http.server
```bash
# Проверьте Python версию
python --version

# Убедитесь, что вы в правильной директории
cd C:\Users\user\TestInterface

# Попробуйте с явным путем
python C:\Users\user\TestInterface\index.html -m http.server 8000
```

### Видео не воспроизводится
- Браузер может не поддерживать формат видео
- Попробуйте преобразовать видео в MP4
